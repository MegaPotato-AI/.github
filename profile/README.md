# MegaPotato

**MegaPotato AI upscaler** ([megapotato.app](https://megapotato.app)): photo super-resolution ×2, ×4 and ×8, up to 16 400 px on the long side, on our own model. A web app and a REST API with the same per-photo prices, pay as you go.

- **API documentation:** [megapotato.app/developers](https://megapotato.app/developers) · [OpenAPI 3.1](https://megapotato.app/developers/openapi.json) · [Markdown](https://megapotato.app/developers.md)
- **Examples:** [megapotato-api-examples](https://github.com/MegaPotato-AI/megapotato-api-examples) (curl, Python, Node.js)
- **ComfyUI node:** [comfyui-megapotato](https://github.com/MegaPotato-AI/comfyui-megapotato), in [ComfyUI Manager](https://registry.comfy.org/nodes/comfyui-megapotato)
- **Benchmark of 18 AI upscalers** (October 2026, blind judges, open data under CC BY 4.0): [megapotato.app/blog/best-ai-image-upscalers-2026](https://megapotato.app/blog/best-ai-image-upscalers-2026)
- **Contact:** support@megapotato.app
